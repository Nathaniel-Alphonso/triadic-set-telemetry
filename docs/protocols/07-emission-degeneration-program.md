# The Emission-Degeneration Program (Public Protocol Summary)

The detector side asks whether degenerate emission can be caught; this program asks what degeneration actually looks like **in the populations being read** — measured, typed, honestly bounded — and iterates the operating point against measured populations rather than argument. Its instruments and fixture families are published under `fixtures/`; this document is the heavily distilled protocol record of the program's design laws.

## 1. Fresh corpora, zero selection freedom

Every fresh adjudication population is built under its own pre-registered one-sheet: source pool, deterministic seeded selection rule, scale, census discipline, acceptance — drafted before the builder exists. The laws:

- **Fresh means new prompts, never re-walks.** No fresh corpus ever re-walks a banked document.
- **Zero selection freedom.** Document selection is deterministic and seeded; the builder has no choice to make, and two consecutive builds must be byte-identical.
- **Contamination guards and disjointness receipts.** The builder proves mechanically that the fresh population is disjoint from the development population — and that no fresh document appears in the prompt prefix every walked prompt carries (contamination by construction, excluded and fail-loud asserted).
- **The split is pinned before the walks.** Calibration and held-out halves are named by a fixed document-id rule before any walk runs, and the census is applied before the split, so no adjudication decision ever touches half-assignment.

## 2. Arming from prior evidence only

The composite candidate reads only the sides that **prior, banked evidence** earned — per lane family, pinned before any fresh data exists. An unarmed side contributes nothing to the document score. The cost is owned in the pre-registration itself: if the fresh corpus would have separated on an unarmed side, this design has surrendered that coverage, and the record says so. Arming is never fresh-data-driven.

## 3. The level-set rule — thresholds as calibration artifacts

One threshold per leg, set at the calibration half's own quantile. Because the combined score fires only when an armed side crosses the threshold, the fired region is a level set of the score — the calibration half's combined fire count is bounded **by construction**, whatever the correlation between sides, whatever the leg size. Thresholds measured at adjudication are never adjudicated constants; the binding operating point is deferred to the wiring phase under its own pre-registration.

## 4. Bar, budget, and the tradeoff clause

- **Two hard gates.** The separation bar (held-out, two standard errors, population guard, jitter clause — inherited verbatim from the fresh-walk protocol) and the clean fire-rate budget — the adjudication's coarse guard is a pinned pre-registered margin (five percent at the fresh-corpus adjudication); the binding operating budget is withheld to the wiring phase per the R7 ladder.
- **Catches are diagnostic, never a gate.** Loop-catch coverage on the fixed fixtures is measured and reported; it never gates the verdict.
- **The overlap line, always visible.** Every leg's output carries the count of clean documents sitting at or above the easiest loop's score. The irreducible overlap between clean and loop populations — the honest possibility that no operating point separates completely — is pre-named, printed on every leg, and never adjudicated away. When the catch objective and the budget conflict on a leg, **the budget governs the verdict and the overlap line names the cost.**

## 5. The kill, and what the record did next

The first fresh adjudication of the composite candidate is part of the public story precisely because it demonstrates the falsifier: **the candidate passed the separation bar on every leg and was killed by the fire-rate budget** — the budget governs even when separation succeeds, and a killed candidate stays killed; successors never re-score it. The program's response, each movement its own pre-registration:

- **Alarm-population forensics.** Characterize the alarmed clean population itself — lengths, stop forms, run structure, mass placement — not just its count, so every refinement is designed against a measured population rather than an assumption.
- **The emission-degeneration census.** An emission-level typing of the corpus, complementary to (never rival of) the label layer: the code leg's pass/fail labels stay execution-based; the census types degeneration shapes. Where no mechanical oracle exists — prose — the census label is **adjudicated by me, document by document**, never instrument-invented; the instrument types, I decide.
- **The specificity refinement.** Shape gates (the persistence and the position of the ceiling excursion) drawn from prior data only, each gated document censused by name, and each refinement re-adjudicated on a **new disjoint population** — the constants pin from prior data, so the fresh corpus is development data for the refinement and its own test must be newer still. Fails-open discipline throughout: unverifiable content never receives an invented verdict.
- **Composition refinements under the one-free-parameter law.** Any composition carries exactly one free parameter, pinned before measurement with no tuning surface; the tool must first reproduce the standing score exactly at the null value (the identity receipt, fail-loud) before any composed reading is measured; and the dev-bytes law governs every transfer: a reading developed on one population never transfers to another — projected near is not measured over.
- **The token-level door.** Later movements read below document level: every content commit role-tagged deterministically (statement onsets, logic commits, signature echoes), with the honest boundary owned — views that bind only where the walk emits code bind only on the code-emitting subset, a view below the population guard reads inconclusive, and the capture window bounds what any walk contains (windowed captures, never full responses; what lies beyond the window is unobservable and never claimed).

## 6. What this program does not do

No actuation, no wiring, no threshold adjudication. No label invention — the instrument types, my stamps decide. No re-scoring of standing verdicts. No promise that overlap can be eliminated — the aim is a budget-passing operating point plus named, visible overlap when it occurs. The detector is read-only telemetry plus offline readout with no channel into the forward pass; nothing wires without bar and budget both passing.
