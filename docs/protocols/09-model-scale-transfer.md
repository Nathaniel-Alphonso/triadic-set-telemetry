# Model-Scale Transfer — the Ladder Protocol (Public Protocol Summary)

The architecture is a family measured across one model family, walked up a scale ladder: the frozen 1B of record, then 3B, then 8B. The ladder exists to answer one pre-registered question and to refuse one tempting failure: it is **built to measure, never to rescue**. A sub-bar read at a new scale is an honest outcome, banked with full receipts — never a summons for rework until the read passes.

## 1. The pre-registered hypothesis

The directional expectation was committed before any ladder run: **depth sharpens signal** — the prediction that a deeper model's trajectory health separates more cleanly, not less. As a pre-registered hypothesis it is falsifiable, and the ladder is its test: a negative read is banked with the same receipts as a positive one, and the prediction's authors do not get to re-aim it after the fact.

## 2. The ladder law — every rung a new bank line

Each scale is a new bank line: its own baselines, its own censuses, its own acceptance receipts, earned on its own measurements. Prior lines freeze — the 1B record stays the 1B's record (doc 02 §4), and no number crosses scales. Drift at a rung is a new bank line, never a silent basis change: if the instrument's environment moves mid-rung, the move is named and the line re-earned, never absorbed.

## 3. The port law — what transfers and what never does

Four pinned classes:

1. **Forms port.** The separation bar (two standard errors, held-out), the jitter clause, the population guard, the normalized depth bands, the feature definitions, the window constants — the instrument's structure rides unchanged across scales.
2. **The instrument is layer-dynamic.** It reads the layer count from the model's own configuration — zero code change between rungs. What adapts, adapts by construction, not by hand.
3. **Constants re-derive.** Every calibration constant is re-derived from the new model's own measurements, never carried from the prior rung. Calibration transfer is itself measured (G10), never assumed — "nothing transfers by assumption" (`ARCHITECTURE_OVERVIEW.md`).
4. **The wired threshold never ports.** It is not carried to a new scale, not re-derived there, and not touched: any threshold decision for a new model is its own pre-registration, gated on that scale's own pass. A threshold earns its wiring per model, or it does not wire.

## 4. The only-variable law

The corpus legs re-walk the adjudicated manifests of record — the model is the only variable that moves. The alternative — generating fresh text at the new scale — is named honestly as a confound and refused for the transfer read: new text would bundle a second variable into what must be a single-variable measurement. Genuinely fresh data has its own protocol (doc 05); the ladder measures the model, and it holds everything else still.

## 5. The component ladder — integration last

Eight rungs, ordered so the cheapest honest kill comes first and the integrated claim is earned last:

1. **The smoke.** The first decode at the new scale measures the memory line and gates every longer run. Per-document cost is measured here, never assumed — the full-session estimate is presented after the smoke, with the repricing caution named: a smoke that under-measures the long runs is a lesson the record already carries, banked as such.
2. **The anchor and bank-line.** Per-leg baselines derived by the instrument from each leg's own clean documents — new numbers, never ported.
3. **State-channel adjudication.** The detector families re-earn separation on the new model's own walks, under doc 05's protocol.
4. **The capture and join.** The routing-channel readout (17-AP, doc 02) captured and joined offline.
5. **The oracle arms replayed.** The Gate 17 family exercised on the new model's outputs (doc 02).
6. **The fixture suites replayed.** The published suites re-run byte-identical — zero suite-byte changes. A census shift on the new emissions is a finding banked, never forced toward the prior rung's bounds.
7. **The structural-loop detector and its baseline.** The Tier C harness re-baselined at the new scale.
8. **Integration, last.** The full governed pipeline runs only after every component carries its own new-scale receipt — an integrated claim is never the instrument's first measurement at a new scale.

## 6. The session discipline

- **Single-session assembly, assembly-only.** The record legs assemble in one session, in a pinned order that is a recommendation, never a dependency — the only hard gates are the smoke and each shared rung's own wait-on law. Nothing is re-derived at the session: every rung consumes its own pinned sheet, its own recorded command forms, its own receipts. Zero tool-byte changes, zero new instruments mid-session.
- **The instance protocol.** The instrument-of-record bytes are hashed on the rented host before anything runs — download, re-hash, compare; a mismatch kills the session before a single decode.
- **The cleanliness receipt.** The working directory is listed for strays from aborted attempts and cleaned before record walks — a stray cache carried into a record walk is a contaminated line by construction.
- **The banner-first law.** The layer line is read by the operator's own eyes before every launch, and a mismatch kills on sight: the wrong model at the wrong rung is a session-ending event, not a note.
- **Shared legs run once, serving every consumer.** A record walk that several downstream rungs consume is never re-walked for convenience; downstream rungs wait on it and read its receipts.
- **Offline acts never block the session.** Passes, joins, and adjudications run CPU-local on banked bytes at zero rental cost, interleaved at the owner's word — the GPU legs are the session; everything mechanical happens after them.
- **Host honesty.** The record host is named with the model change, never hidden: the hardware rides with the scale as a named bundle, and every cross-scale comparison says which host it ran on.

## 7. The 3B rung — an honest skip

The 3B rung was closed as skipped by owner ruling on the evidence then in hand. Its development receipts remain in the record as a caution, never as a comparison basis: no 3B number is read against either neighbor rung, and the ladder's question passes to 8B unanswered at 3B — stated plainly rather than papered over.

## 8. Ownership and receipts

- **Owner-side runs only.** Every GPU leg runs at the owner's single-session word, on the owner's side of the interface; the assistant side executes zero decodes. The ladder's evidence is the owner's runs, or it does not exist.
- **Namespace law.** Every artifact at a new rung carries the rung's own tag namespace — a scale's artifacts are collision-guarded by construction, and walk-identity receipts confirm zero prior-scale text in the new artifacts.
- **Checksummed inputs.** Model shards are checksummed at download and the checksums banked; a drifted shard is a hard exit, never a warning.

## 9. What this ladder does not do

No rescue: a sub-bar read is banked, never re-worked into a pass. No silent basis change. No threshold set, moved, or adjudicated at any rung. No calibration carried between scales. No comparison against a skipped rung's receipts. Nothing runs before its pre-registration carries the owner's stamp.
